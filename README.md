# Уток — демонстрационный сайт швейного производства

[Главная](https://orbeeeotherprod-lab.github.io/utok-garment-prototype/) · [Пошаговая заявка](https://orbeeeotherprod-lab.github.io/utok-garment-prototype/request/)

«Уток» — условный бренд. Изображения и описания иллюстрируют концепцию. Сайт сохраняет noindex,nofollow; форма и файлы никуда не отправляются.

Содержимое репозитория — готовая статическая сборка для GitHub Pages. Источник публикации: main, корневая папка. Файл .nojekyll отключает Jekyll.

Использованы React Bits (David Haz, MIT + Commons Clause), React и Motion. Полные уведомления: assets/third-party-notices.txt.
